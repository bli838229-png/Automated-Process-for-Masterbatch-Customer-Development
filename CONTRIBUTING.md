# Contributing

Thanks for your interest in contributing to **Masterbatch Lead Gen**! 🎨

This is a methodology + prompt-library Skill for overseas lead generation in the masterbatch industry. Contributions that make it more useful for real exporters are very welcome.

## Ways to contribute

- **Add a language**: translate `SKILL.md` / `README` into a new market language, or add local-language outreach templates and search keywords.
- **Improve domain knowledge**: correct or extend `references/industry-knowledge.md`.
- **Add outreach templates**: new languages, industries, or tones in `references/outreach-templates.md`.
- **Fix bugs / typos** in prompts or docs.
- **Report issues** with the GitHub issue tracker.

## Guidelines

1. **Keep it factual.** Never add fabricated company names, emails, certifications, or examples.
2. **Respect the safety boundaries** in `references/safety-compliance.md` (no automated outbound sends, no unofficial WhatsApp/LinkedIn automation).
3. **Follow the existing file structure**:
   ```
   SKILL.md
   references/*.md
   examples/*.md, *.csv
   README.*.md        # localized READMEs
   ```
4. **Match the existing tone**: professional, concise, pragmatic.

## Pull requests

1. Fork the repo and create a branch.
2. Make focused changes; one concern per PR.
3. Keep Markdown formatting consistent (tables, code fences).
4. Open a PR with a clear description of what changed and why.
